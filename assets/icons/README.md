# VHH SVG icons

Twenty-one custom, platform-neutral outline icons. All use a 24 × 24 viewBox, 1.5px stroke, round caps/joins and editable vector geometry. There are no embedded images or font dependencies.

Figma masters live on Foundations and use proportional constraints for 16px chevrons, 20px sidebar/attachment slots, 24px navigation and 32px state emblems. Navigation tabs are 93 × 56, centred above an 11px label with a 4px gap. Driver action/row touch targets remain at least 48 × 48.

Components expose icon instance-swap properties and editable labels. Preserve transparent SVG frame backgrounds; tint the vector paths. Brand lettering is separate outlined artwork in [the brand directory](../brand/CONVERSION.md).
