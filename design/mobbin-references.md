# Selected Mobbin patterns for VHH Fleet

**Put the next action beside the information needed to take it.** Use the following two references as Fleet's starting point for the web overview and driver home. Apply their structure with Fleet's own [components and theme](../DESIGN.md).

| Surface | Selected reference | Decision in Fleet |
| --- | --- | --- |
| Web overview | [Remote dashboard](https://mobbin.com/screens/ca14250d-c897-4a2b-b87f-d1f9b50c8ab1) | Remote groups common destinations under Quick actions. Fleet uses a short group of permission-checked links to Exceptions, Driver schedule, Vehicles and Drivers. Each link names its destination and what staff can do there. |
| Driver home | [Jobber task details (iOS)](https://mobbin.com/screens/96d24bf8-5eaa-44cb-b687-f7c353419b42) | Jobber puts its main action directly after the details it applies to. Fleet shows the vehicle registration and state immediately above confirmation. When confirmation is blocked by a pending review, the next action is to check for updates. |

When working on another feature, search for that specific employee task. Record a reference here only after selecting the pattern Fleet will use. An older [research log](../DESIGN_DIRECTION.md#mobbin-references-inspected) preserves earlier exploration.
